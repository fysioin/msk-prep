# Simplified plain-English companion (all 16 papers)

`index.html` is a single self-contained study companion for the RGUHS MPT-MSK
question papers (Papers I-IV, Nov 2023 to Nov 2025). It is a plain-English,
bullet-point rewrite of all 160 model answers, with tap/hover pop-ups for
difficult terms.

- 160 questions | 16 papers | 571 glossary terms | 3,358 answer points
- One file, no external assets; works offline; mobile-friendly.
- Pop-ups combine the project's own glossary with a curated plain-English set.

Simplified from the main app (`index.html` on `main`). Unofficial study aid -
not an official answer key; always cross-check with your college faculty.
